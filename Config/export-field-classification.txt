# Every stored column, classified — what it is, and whether it may ever leave this app.
#
# WHY THIS FILE EXISTS. The e09 plan's §7 asks a harder question than "does the export leak?".
# It asks whether an epic creates the first column that *could*. A registry answers it in the
# only way a repository can: every column carries a row somebody wrote, a column with no row
# fails the gate, and the failure lands on whichever epic added the column rather than on the
# epic that finally writes an exporter. `scripts/check-export-fields.sh` reads it, in the shape
# `Config/string-draw-sites.txt` and `Config/verbatim-sites.txt` already established.
#
# NO EXPORTER EXISTS YET. This registry lands first on purpose (e09a T2), so that the exporter
# arrives into an enforcing gate. It is deliberately independent of any exporter's own manifest:
# a lint that read the exporter's field list to decide what to require would be the exporter
# marking its own homework, and the two have to be able to disagree.
#
# THE CURRENT SCHEMA ONLY. v1…v7 are frozen migration sources; nothing fetches them and no
# exporter can reach them. The script derives the current entity set the way the schema chain
# does — for each entity name, the declaration in the highest-numbered schema wins — so a
# version that re-declares a class cannot leave this file describing the old columns.
#
# ROW FORMAT
#
#   <entity> | <column> | <class> | <what it is>
#
# THE FIVE CLASSES
#
#   KEY       bundle identifiers, normalised `scheme://host[:port]` origins, UUIDs
#   TOKEN     closed-vocabulary raw values and NormalisedTokens — re-derived on the way out,
#             never copied, so an unknown raw value cannot ride out of the app as a string
#   MEASURE   instants, durations, counts, booleans
#   OWN       the person's own typed words. Exportable BECAUSE it is theirs
#   EXCLUDED  never leaves, and the row says why
#
# THE CLASS IS A JUDGEMENT AND THE FOURTH FIELD IS THE ARGUMENT. No script can check whether a
# classification is right; what the script guarantees is that somebody made it, in a file a
# reviewer can read. The sharpest edge in here is `ContextItem.value`, which for a file item IS
# an absolute path. It is classified OWN because the person *attached* it — the app never
# observed it — and that distinction is the whole basis on which it could be exported at all.
# Under §7 it belongs to an Everything scope only, named in the published field list before any
# panel opens, and never to Sessions or Judgements.
#
# WHAT NEVER LEAVES, restated as a list a reviewer can check against the rows below: window
# titles, URLs beyond a normalised origin, document names, file paths the app observed, OCR
# text, image data of any kind, keystroke or input content, security-scoped bookmark blobs,
# machine identifiers, Keychain material, and any similarity number.
