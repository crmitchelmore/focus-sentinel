# Every `verbatim:` in the shipping graph, and what it draws.
#
# `scripts/check-strings.sh` reads this file. See the "== registered verbatim sites" section of
# that script for what it asserts and — more importantly — for what it deliberately does not.
#
# The short version: `Text(verbatim:)` is the one construct the string lint exempts by design,
# and it is how three separate defects reached a person's screen with the gate green (focus-7gc,
# focus-7zr, focus-7to). The exemption is correct — a file path, a ⌘W glyph and somebody's own
# sentence must never be sent through a catalog — so the answer is not to withdraw it but to make
# every use of it a stated act. A row here is that statement. It does not make the drawing right;
# it makes it visible, and it makes adding a new one something a diff shows.
#
# Format, one site per line:
#
#     <path> | <the expression, exactly as the line has it> | <what it draws>
#
# A line is keyed on the path and the expression, so editing what a site draws is a diff here as
# well as in the source. Order and blank lines do not matter; `#` starts a comment.
#
# The four kinds, and every row below is one of them:
#
#   OWN      the person's own material — their sentence, their file path, their keyword. The
#            reason the exemption exists.
#   NAME     a display name resolved from a key. `NudgeSubject`/`SubjectDisplay` decide it, never
#            the call site, and the key half is never what is drawn (R-96o).
#   NUMBER   a number or a span, through a locale-aware formatter. Never string interpolation of
#            an Int — that draws Western Arabic digits in every locale.
#   RESOLVED a catalog string that has already been looked up, transformed and substituted, so
#            the literal is gone by the time it gets here. `ShellText` and `NudgeText` only.
